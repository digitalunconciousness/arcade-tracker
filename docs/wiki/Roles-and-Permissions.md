# Roles and permissions

Every account has one of four roles. Each role can do everything the roles above it in this table
can, and more. The menu only offers what a role can open.

| Role | For | Can |
|---|---|---|
| **Read-only** | Owners, front of house | See the dashboard, machines, work orders, maintenance tasks, rail history; scan labels |
| **Operator** | Techs and floor staff | Record plays and run collection rounds; report problems and log work; add and edit machines; take, add, move and count stock; request parts; receive their own requests and deliveries; print labels |
| **Manager** | Whoever runs the floor | Reports and graphs; the rotation planner; maintenance tasks; add and edit parts; the shopping list and purchase orders; review counts; receive any request; coin-door labels; import a roster; see supplier account numbers |
| **Admin** | One or two people | Users, alerts, GATBOX devices, branding, storage and backups |

Players don't need an account: the coin-door form is the only page that takes input without
signing in.

The first account, made on the [first run](Getting-Started#first-sign-in), is an admin.

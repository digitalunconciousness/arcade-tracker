# arcade-tracker server, where these packages have no importer under app/.
# Install alongside the server requirements:
#   pip install -r requirements.txt -r requirements-pi.txt

# import in try/except because it is unavailable off a Pi. gpiozero and pyserial
# moved back to requirements.txt -- the skeeball routes import them transitively,
# mock mode included, so the server needs them.

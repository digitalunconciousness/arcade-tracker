Coin-door labels

These labels go inside the coin door. Each one is a key: whoever can read the QR can file a maintenance request for that machine without logging in. That is the point — but it also means a label stuck on the outside of a cabinet, or photographed, is a credential handed out. The public labels under Label sheet are the ones that go where people can see them.
